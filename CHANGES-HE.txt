גרסת מפה: +15% גופן ותיבת בחירה נקייה

1. כל שמות החנויות ההתחלתיים גדולים ב-15% (עם עשירית נקודה).
2. מיקומים ידניים שנשמרו בדפדפן נשמרים; גודל הגופן שלהם מוגדל פעם אחת בלבד, בלי הגדלה חוזרת לאחר רענון.
3. תיבות חדשות מתחילות בגודל גופן 16.1.
4. מסגרת בחירה כחולה ודקה מחוץ לתיבה, ארבע ידיות פינתיות קטנות וידית סיבוב מעליה.
5. כפתורי הזום, ההעתקה וההדבקה נשמרו.

כדי להפעיל ב-Windows: חלצו ZIP, פתחו CMD בתיקיית הפרויקט והפעילו בשורות נפרדות:
npm install
npm run dev

כדאי לשמור גיבוי קודם באמצעות Export JSON לפני עבודה ממושכת.
