עדכון: הגדלה והקטנה של המפה

בפינה הימנית התחתונה של המפה: 
+  הגדלה ב-25%
-  הקטנה ב-20%
התאם למסך - איפוס הזום והתאמת שתי הקומות לגודל החלון.
האחוזים הם ביחס לגודל ההתאמה למסך (100% = Fit).

כשהמפה מוגדלת מעבר לחלון, ניתן לגלול למעלה, למטה ולצדדים.
הזום משפיע על הרקע ועל כל תיבות החנויות יחד, ללא שינוי במיקום השמור שלהן.
מנגנוני בחירה, גרירה, סיבוב, שינוי גודל, העתקה והדבקה נשארו בקוד.

הפעלה ב-Windows:
1. חלצי את ה-ZIP לתיקייה חדשה.
2. פתחי CMD מתוך התיקייה שמכילה package.json.
3. הריצי: npm install
4. הריצי: npm run dev
5. פתחי בדפדפן את הכתובת שתופיע.

שמירת תיקונים שביצעת: השתמשי ב-Export JSON לפני מעבר גרסה,
ובמידת הצורך ב-Import JSON לשחזור. מפתח השמירה של הגרסה
הקודמת נשאר ללא שינוי: mall-map-aligned-v4.
