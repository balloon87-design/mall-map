קיצורי מקלדת ומיקום בקרי זום

Ctrl + Plus (+ או =; כולל המקלדת הנומרית): הגדלת המפה.
Ctrl + Minus (-; כולל המקלדת הנומרית): הקטנת המפה.
הקיצורים שולטים בזום של המפה, לא בזום הכללי של הדפדפן.
הכפתורים הגדלה, הקטנה והתאמה למסך נשארים בפינה השמאלית העליונה של אזור המפה גם בזמן גלילה.
הגרסה מבוססת על המפה האחרונה עם גופנים מוגדלים ומסגרת בחירה נקייה.

הפעלה:
1. חלצו את התיקייה.
2. פתחו CMD בתיקיית הפרויקט.
3. npm install
4. npm run dev

לפני מעבר לגרסה החדשה, מומלץ לייצא JSON בגרסה הישנה.
