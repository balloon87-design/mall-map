מפת קניון: מיקומים ידניים משופרים, גרסת ניסיון

1. חלצי תיקייה חדשה, פתחי CMD באותה תיקייה.
2. הריצי npm install (פקודה אחת) ולאחריה npm run dev (פקודה שנייה).
3. המפה אמורה להתחיל ממיקומי החנויות החדשים: נשמר מפתח אחסון חדש mall-map-aligned-v4.
4. לחצי על תיבה וגררי אותה לתיקון נקודתי. שמרי בכפתור Save.
5. לחצי Export JSON כדי לשמור גיבוי חיצוני לכל המיקומים.
6. העתקה/הדבקה נשארות מהגרסה האחרונה שעבדה.

חשוב: אלה מיקומים ידניים משוערים המותאמים למפה הנקייה, לא אימות מדויק לכל חנות.
אחרי שינויים שמורים הימנעי מחילוץ גרסה נוספת על גבי אותה תיקייה.
